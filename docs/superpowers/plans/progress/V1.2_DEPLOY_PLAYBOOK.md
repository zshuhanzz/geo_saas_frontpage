## 4. Cloud Run 环境变量 gating

在 `gcloud run services update` 前确认:

| Service | Variable | Prod value | 作用 |
|---|---|---|---|
| `geo-admin-api` | `APP_ENV` | **MUST NOT be set**（或 `production`）| `APP_ENV=local\|dev` 会让 `/jobs/*/run` 返回 stub，prod 必须真触发 |
| `geo-admin-api` | `ADMIN_API_URL` | 实际 Cloud Run URL | scheduler → admin HTTP target |
| `geo-admin-api` | `INVOKER_SERVICE_ACCOUNT` | 实际 SA email | OIDC audience |
| `geo-admin-api` | `GCP_PROJECT_ID` | prod project id | |
| `geo-admin-api` | `GCP_REGION` | `us-central1` | |
| `geo-saas-web` (build) | `VITE_DEV_AUTH_USER_EMAIL` | **MUST NOT be set** | OAuth 全绕过漏洞 |
| `geo-admin-web` (build) | `VITE_DEV_AUTH_USER_EMAIL` | **MUST NOT be set** | 同上 |

```bash
# 4.1 审计 admin_api env —— 应无 APP_ENV
gcloud run services describe geo-admin-api --region=us-central1 \
  --format="value(spec.template.spec.containers[0].env[].name)" \
  | tr ',' '\n' | grep -i APP_ENV || echo "APP_ENV not set — OK"

# 4.2 审计 web build —— 应无 dev bypass 变量
grep -r "VITE_DEV_AUTH_USER_EMAIL" geo_saas/web/dist/ 2>/dev/null \
  && echo "!!! LEAKED !!!" || echo "web dist clean — OK"
```

**web build 注意事项**:production build 用 `npm run build` 默认 `--mode production`，仅加载 `.env.production` / `.env`，绝不加载 `.env.claude.local`。如果 CI 显式传 `--mode claude` 就出事，检查 build script 别误传。

## 7. Rollback

| Scope | Command |
|---|---|
| Cloud Run service | `gcloud run services update-traffic <svc> --to-revisions=<prev>=100 --region=us-central1` |
| Migration 052 | 运行 `052_v12_content_wizard_reorder.sql` 底部的 rollback SQL（部分可逆） + 恢复 pre-migration pg_dump |
| Migration 051 | `DELETE FROM geo_workflow_config WHERE scope='content_generation' AND ((config_type='workflow_step' AND key='mode_gate') OR (config_type='mode_option' AND key IN ('manual','ai_discover')));` + `UPDATE geo_report_templates SET wizard_config = wizard_config #- '{steps,mode_gate}' WHERE task_type='content_generation';` |
| Migration 050 | `DELETE FROM geo_workflow_config WHERE key='channel_performance' AND scope='analysis' AND config_type='goal';` + restore 渠道表现分析 wizard_config 备份 |
| Migration 049 | `ALTER TABLE geo_clients DROP COLUMN cron_llm_discovery;` |
| Migration 042/044/045 | **必须从 pg_dump 恢复**（destructive） |
| Terraform IAM | `terraform destroy -target=google_cloud_run_v2_job_iam_member.admin_api_llm_batch_invoker` |

**关键原则**:保留 pre-migration pg_dump **7 天**。任何 DB-level rollback 先从 dump 恢复再打 patch SQL。
